# HackerRank Problem Solving

This repository contains my solutions for the five HackerRank problems completed as part of the problem-solving activity.

## Problems

| No. | Problem | Approach | Time Complexity | Space Complexity |
|---|---|---|---|---|
| 1 | Diagonal Difference | Traverse both diagonals and find their absolute difference | O(N) | O(1) |
| 2 | Dynamic Array | Use a vector of sequences and process queries using XOR | O(Q) average | O(N + Q) |
| 3 | Time Conversion | Convert the 12-hour format hour to 24-hour format | O(1) | O(1) |
| 4 | Compare the Triplets | Compare corresponding elements of Alice and Bob's arrays | O(1) | O(1) |
| 5 | Sparse Arrays | Store string frequencies using a hash map | O(N + Q) average | O(N) |

## Files

## Learning Reflection

Through these problems, I practiced arrays, vectors, strings, loops, conditional statements, hash maps, and basic problem-solving techniques. I also learned how to think about time and space complexity while writing solutions.

The problems helped me understand how the same basic programming concepts can be applied to different types of problems. I also practiced submitting solutions on HackerRank and organizing my work using GitHub.
